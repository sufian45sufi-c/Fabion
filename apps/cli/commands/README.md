# CLI Commands

Each file in this folder defines one CLI command.

Commands are loaded by `index.js` and available in the REPL.

## Planned commands

| Command | File | Description |
|---|---|---|
| `/inspect` | `inspect.js` | Inspect the current project structure |
| `/git` | `git.js` | Show git status and recent commits |
| `/run` | `run.js` | Run a shell command with agent oversight |
| `/skill` | `skill.js` | Load or list available skills |

Commands are added in Phase 3 alongside the tool system.
